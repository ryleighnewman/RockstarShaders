# Rockstar Shaders Privacy Policy

Last updated: 2026-09-19

This policy covers the Rockstar Shaders mod (the "Software") and the website at https://rockstarshaders.com (the "Site"), both made by Ryleigh Newman.

## The short version

Neither the Software nor the Site collects personal data. The Software makes no network connections of its own. The Site has no accounts, cookies, analytics or forms.

## The Software

- **No network use.** The Software does not connect to any server, does not check for updates, does not send crash reports, and has no telemetry. Everything it does happens on your computer.
- **What it writes to your disk.** A settings file, `config/rockstarshaders.json`, inside your Minecraft game folder, holding the values you chose on its settings screens; lines in Minecraft's own log files (`logs/latest.log`) that describe what the Software did while the game ran; and, if you generate the extended horizon, cached terrain data inside the game folder. All of it stays on your computer and you can delete it at any time.
- **What it reads.** Your Minecraft world data, resource packs and options, in order to render them. It reads nothing outside the game folder.
- **Minecraft itself.** Minecraft: Java Edition, the Fabric loader and any other mod you install have their own behavior and their own policies. This policy does not cover them.

## The Site

- **Hosting.** The Site is static files served by Cloudflare. Cloudflare, like every host, keeps ordinary server logs (the address a request came from, the page requested, the time, the browser's identification string) for security and operation, under Cloudflare's own privacy policy. The author does not use those logs to identify visitors.
- **No cookies, no analytics, no tracking pixels, no accounts, no forms, no newsletter.**
- **Embedded and linked services.** Pages link to Modrinth, GitHub and YouTube. Following a link takes you to that service, under its own policy. A video on the home page is a file served from the Site, not an embed from YouTube.
- **Search engines.** The Site publishes a sitemap and, after each update, tells search engines it changed (the IndexNow protocol). That sends the Site's own addresses, nothing about visitors.

## Downloads, GitHub and support

If you download the Software from Modrinth or GitHub, that service handles the download under its own policy; the author sees only the aggregate download counts those services show. If you open an issue on GitHub or send an email, the author keeps that correspondence, including any log file or screenshot you attach, for as long as it is useful to fix the problem. Log files can contain your computer's user name and folder paths; remove anything you do not want to share before sending.

## Children

The Software and the Site are not directed at children under 13 and collect no data from anyone.

## Changes

If this policy changes, the new version is published at https://rockstarshaders.com/privacy with a new date.
